# Media Manifest

The original repository assets listed below were available locally and copied without transformation. The supplied HORUSIA logo was copied byte-for-byte from the user's attachment into the theme assets.

| File | Intended use | Status |
|---|---|---|
| `assets/horusia-logo.png` | Header/footer logo fallback | User-supplied PNG, 1792 x 592; copied unchanged. It is fully opaque with a dark navy background, not transparent. Theme header/footer backgrounds use the matching navy. Owner may replace it with an image picker in Shopify. |
| `logo.jpg` | Legacy source logo candidate | Available but is not used as the new HORUSIA logo |
| `hero-banner.jpg` | Homepage hero candidate | Available; owner review and Shopify upload required |
| `egyptian-goddess.jpg` | Heritage/content image candidate | Available; owner review and placement required |
| `tutankhamun-mask.jpg` | Heritage/content image candidate | Available; owner review and placement required |
| `tutankhamun-throne.jpg` | Heritage/content image candidate | Available; owner review and placement required |
| `share-preview.jpg` | Legacy preview image; do not reuse as stale Lovable metadata | Available; replace with verified current campaign/store image |

## Unavailable or missing

- Live Shopify product images
- Live Shopify collection images
- Additional banners referenced only by database configuration
- Source binary assets not present in `src/assets/`
- Video assets
- Transparent HORUSIA logo source; the supplied PNG has no alpha transparency

Unavailable database-hosted or Lovable/Supabase URLs must not be used in the finished storefront without owner review and Shopify media upload.
