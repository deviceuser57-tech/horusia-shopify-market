# Dependency Removal Report

## Excluded from theme runtime

- React and React Router
- Vite and React preview assets
- Supabase authentication, database, storage, edge functions, and types
- Lovable SDKs, Lovable preview bridges, Lovable telemetry, and Lovable MCP
- Hardcoded custom Shopify Storefront API configuration
- Custom operational dashboards and admin guards
- Supplier and affiliate connectors
- Custom AI/trend services
- Custom checkout, payment gateway selectors, payment webhooks, and custom checkout creation
- Custom newsletter database writes
- Browser-authoritative cart prices
- Lovable/static robots, sitemap, canonical, and Open Graph metadata

## Preserved outside uploadable theme

The original source remains in place. No original database or service has been deleted or rotated.

## Credentials

No credential values are included in this theme. The original `.env` file was not copied or printed. Any live credentials it contains require owner review for removal or rotation according to the owner's migration plan.
