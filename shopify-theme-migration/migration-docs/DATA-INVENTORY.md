# Data and Field Mapping Inventory

Live Shopify data export, source database access, and a complete product/media export were not available during this migration session. No product records or variants are guessed.

## Product fields

Required Shopify product fields:

- Title
- Description
- Handle
- Product type
- Vendor
- Tags
- Published status
- SEO title and description
- Featured image
- Additional media and alt text
- Variant title
- Option names and values
- SKU
- Barcode
- Price
- Compare-at price
- Cost (admin only)
- Inventory policy
- Inventory quantity
- Weight
- Product/variant metafields

Do not export customer, payment, supplier, or payment credentials.

## Collections

Map source categories to Shopify collections. The owner must decide which collections are manual and which are automated.

## Informational content

Preserve and review:

- About story and values
- Contact information
- Services and inquiry copy
- Shipping page
- Refund/returns page
- Privacy page
- Terms page

Policies must use Shopify's configured policy objects. Unverified free-shipping, delivery, refund, and guarantee claims must not be published.

## Missing export

Missing:

- Authorized live Shopify or source database export
- Product/variant records
- Collection membership
- Inventory records
- Existing content pages
- Navigation menu export
- Customer account configuration
- Installed app configuration
- Policy text approved by the owner
